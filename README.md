# professional-recruitment-plan

## خطة التدريب الاحترافية

تمت إضافة [خطة تدريب احترافية في الاستقطاب والتوظيف](خطة-تدريب-احترافية.md) لمدة 12 أسبوعًا، تتضمن:

- أهدافًا تعليمية وكفاءات مستهدفة.
- برنامجًا أسبوعيًا قائمًا على التطبيق والمحاكاة.
- مشروع تخرج يوثق دورة التوظيف كاملة.
- نظام تقييم ومؤشرات أداء قابلة للقياس.
- قوالب وضوابط للعدالة والسرية والامتثال.

## ملف Excel السنوي

يتضمن [ملف خطة التدريب السنوية وفق محاور GAHAR](خطة-تدريب-سنوية-طبقا-لمعايير-جهار.xlsx):

- خطة شهرية تغطي موضوعات حقوق المريض، مكافحة العدوى، سلامة الدواء، السلامة المهنية، الجودة، التوثيق، والطوارئ.
- مصفوفة كفاءات للعاملين وسجل حضور وتقييم قبلي وبعدي.
- سجل أدلة جاهز للمراجعة والزيارة، مع حالات تنفيذ وقوائم منسدلة.

الملف أداة تشغيلية قابلة للتخصيص، ويجب مراجعته مقابل آخر إصدار رسمي من دليل GAHAR ونطاق المنشأة قبل الاعتماد.
