# professional-recruitment-plan

## خطة التدريب الاحترافية

تمت إضافة [خطة تدريب احترافية في الاستقطاب والتوظيف](خطة-تدريب-احترافية.md) لمدة 12 أسبوعًا، تتضمن:

- أهدافًا تعليمية وكفاءات مستهدفة.
- برنامجًا أسبوعيًا قائمًا على التطبيق والمحاكاة.
- مشروع تخرج يوثق دورة التوظيف كاملة.
- نظام تقييم ومؤشرات أداء قابلة للقياس.
- قوالب وضوابط للعدالة والسرية والامتثال.

## ملف Excel السنوي

يتضمن [ملف خطة التدريب السنوية المترابطة وفق محاور GAHAR](خطة-تدريب-سنوية-مترابطة.xlsx):

- قاعدة موظفين بأكواد موحدة، وخطة تدريب بأكواد أنشطة.
- سجل حضور مركزي يملأ اسم الموظف وموضوع النشاط تلقائيًا من الأكواد.
- سجل تقييمات يحسب النتيجة تلقائيًا ويحدد الحاجة إلى إعادة التدريب.
- مؤشرات إكمال الموظفين، عدد الحضور، تنفيذ الخطة، ومتوسط التقييم في لوحة تحكم.
- نموذجا حضور وتقييم للطباعة، وسجل أدلة مرتبط بدورة التدريب.

ابدأ بإدخال البيانات في شيت **الموظفون** ثم حدّد الأنشطة في **الخطة**. بعد ذلك أدخل كود النشاط وكود الموظف فقط في شيتَي **الحضور** و**التقييمات** لتعمل المعادلات ولوحة التحكم تلقائيًا. الملف أداة تشغيلية قابلة للتخصيص، ويجب مراجعته مقابل آخر إصدار رسمي من دليل GAHAR ونطاق المنشأة قبل الاعتماد.
